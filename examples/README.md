# EXAMPLE content (replace it)

Everything in this folder is a neutral **example** so a fresh install has something to show.
The setup bot copies it to the student's content folder (default `/workspace/study`) and then the
student's coach bot replaces it with a real roadmap and real lessons for their field.

- `roadmap.md`: example plan. The `## Current position` section is sent to the chat bot as context.
- `curriculum.json`: months, units and lessons, in path order. 2 example lessons.
- `lessons/*.md`: one file per lesson id. `ex-plan-your-week` has a ```submit work box.
- `opportunities.md`: empty table; the opportunities bot fills in rows.

The format is documented in [../CONTENT.md](../CONTENT.md).
